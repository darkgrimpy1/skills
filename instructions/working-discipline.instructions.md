applyTo: '**'
description: 'Always follow this instruction when planning or making changes.'
---

Ask, don't assume. If something is unclear, ask before writing any code. Never assume intent, architecture, or requirements.

Simplest solution first. Implement the simplest thing that works. Add no abstraction or flexibility that wasn't requested.

Don't touch unrelated code. If a file or function is not part of the current task, leave it, even if it could be improved.

Flag uncertainty explicitly. If you are not confident about an approach or detail, say so before proceeding. False confidence does more damage than admitting a gap.
